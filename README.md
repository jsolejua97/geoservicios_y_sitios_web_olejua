## 📌 Descripción del proyecto

Este repositorio tiene como propósito almacenar, organizar y documentar el desarrollo del trabajo final de la asignatura **Servicios SIG y Web**.

El proyecto está orientado al diseño, desarrollo e implementación de una solución basada en tecnologías de Sistemas de Información Geográfica (SIG) y herramientas de desarrollo web, con el objetivo de integrar información geoespacial, servicios de mapas y recursos tecnológicos que permitan consultar, visualizar, gestionar y analizar información territorial a través de plataformas web.

Se busca aplicar los conocimientos adquiridos durante el desarrollo de la asignatura, explorando las posibilidades que ofrecen los servicios geoespaciales para facilitar el acceso, la interoperabilidad y la publicación de información espacial en entornos digitales.

## 🎯 Objetivo general

Desarrollar una solución geoespacial web mediante la integración de tecnologías SIG y herramientas de desarrollo web, aplicando conceptos de publicación de información geográfica, consumo de servicios espaciales, visualización cartográfica e interoperabilidad, como resultado del proceso de aprendizaje de la asignatura Servicios SIG y Web.

## 🎯 Objetivos específicos

- Aplicar conceptos fundamentales de los servicios de información geográfica en entornos web.
- Explorar herramientas y tecnologías para la publicación y visualización de información espacial.
- Integrar datos geográficos con componentes y funcionalidades web.
- Implementar mecanismos de consulta e interacción con información geoespacial.
- Documentar el proceso de desarrollo, configuración e implementación de la solución.

## 🗺️ Alcance del proyecto

El repositorio servirá como espacio de trabajo para el desarrollo progresivo de la solución, incluyendo:

- Organización y preparación de información geográfica.
- Configuración de herramientas y entornos de desarrollo.
- Implementación de servicios SIG.
- Desarrollo de componentes de visualización cartográfica web.
- Integración de información espacial y recursos web.
- Documentación técnica y académica del trabajo final.

## ⚙️ Configuración del entorno de desarrollo

Para trabajar con el proyecto se utiliza un entorno virtual de Python, que permite gestionar las dependencias de manera independiente.

Creación del entorno:

```bash
python -m venv .venv
```

Activación en Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Instalación de dependencias (cuando se encuentre disponible el archivo de requerimientos):

```bash
pip install -r requirements.txt
```
